# DayLoop

DayLoop is a personal daily habit tracker for Android — habits, timed routines, medications and day planning in one calm, fast app.

**Design:** Higgsfield-style bento UI — matte black tiles, one acid-green accent, everything for today on a single glanceable grid.

## Features (roadmap)

- **Today bento grid** — progress ring, streak, next medication dose, routines and your week at a glance
- **Habits** — one-tap check-ins, forgiving strength scores (a missed day never wipes your progress)
- **Medications** — per-dose Taken / Skipped / Later with actual times, pill counts and refill countdowns, real phone notifications
- **Routines** — ordered timed steps with a full-screen Run mode
- **Progress** — streaks, weekly targets and a heatmap of your year

## Status

v0.2.0 — working tracker: add habits, medications, routines and plans, one-tap check-ins, streaks, permanent release signing.
